# Statistical and Mathematical Number Theory

多項式階差演算から生じる「連鎖分割（Linked Partitions）」の代数的構造を解明し、離散べき乗和の完全対称核分解、および複素領域への解析接続を研究するドキュメント群です。

## プロジェクトの核心 (Current Focus)

本プロジェクトは、有限べき乗和 $S(a, b, n)$ を普遍的な「対称核」 $S_k$ へと還元する連鎖分割理論を基軸としています。2025年末の理論構築から、現在は複素解析、微分演算子、およびチェビシェフ多項式との双対性に至るまで研究を拡張しています。
