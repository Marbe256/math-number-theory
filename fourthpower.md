# 📐 $(n+k)^4$ の差分操作の算出（k=0からk=4）

## 1. 0階差分（元の式）

$$(n+k)^4 = \sum_{r=0}^{4} \binom{4}{r} n^{4-r} k^{r} = \binom{4}{0}n^4 k^0 + \binom{4}{1}n^3 k^1 + \binom{4}{2}n^2 k^2 + \binom{4}{3}n k^3 + \binom{4}{4}n^0 k^4$$

|  $k$  | 左辺        | 右辺                                                                                                          |
| :---: | :---------- | :------------------------------------------------------------------------------------------------------------ |
| **0** | $$(n+0)^4$$ | $$\binom{4}{0}n^4$$                                                                                           |
| **1** | $$(n+1)^4$$ | $$\binom{4}{0}n^4 1^0 + \binom{4}{1}n^3 1^1 + \binom{4}{2}n^2 1^2 + \binom{4}{3}n 1^3 + \binom{4}{4}n^0 1^4$$ |
| **2** | $$(n+2)^4$$ | $$\binom{4}{0}n^4 2^0 + \binom{4}{1}n^3 2^1 + \binom{4}{2}n^2 2^2 + \binom{4}{3}n 2^3 + \binom{4}{4}n^0 2^4$$ |
| **3** | $$(n+3)^4$$ | $$\binom{4}{0}n^4 3^0 + \binom{4}{1}n^3 3^1 + \binom{4}{2}n^2 3^2 + \binom{4}{3}n 3^3 + \binom{4}{4}n^0 3^4$$ |
| **4** | $$(n+4)^4$$ | $$\binom{4}{0}n^4 4^0 + \binom{4}{1}n^3 4^1 + \binom{4}{2}n^2 4^2 + \binom{4}{3}n 4^3 + \binom{4}{4}n^0 4^4$$ |

## 2. 1階差分 ($\Delta$)

$$
(n+k+1)^4 - (n+k)^4 = \sum_{r=1}^{4} \binom{4}{r} n^{4-r} \left[ (k+1)^{r} - k^{r} \right]
$$

|  $k$  | 左辺                  | 右辺                                                                                                        |
| :---: | :-------------------- | :---------------------------------------------------------------------------------------------------------- |
| **0** | $$(n+1)^4 - (n+0)^4$$ | $$\binom{4}{1}(1^1-0^1) n^3 + \binom{4}{2}(1^2-0^2) n^2 + \binom{4}{3}(1^3-0^3) n + \binom{4}{4}(1^4-0^4)$$ |
| **1** | $$(n+2)^4 - (n+1)^4$$ | $$\binom{4}{1}(2^1-1^1) n^3 + \binom{4}{2}(2^2-1^2) n^2 + \binom{4}{3}(2^3-1^3) n + \binom{4}{4}(2^4-1^4)$$ |
| **2** | $$(n+3)^4 - (n+2)^4$$ | $$\binom{4}{1}(3^1-2^1) n^3 + \binom{4}{2}(3^2-2^2) n^2 + \binom{4}{3}(3^3-2^3) n + \binom{4}{4}(3^4-2^4)$$ |
| **3** | $$(n+4)^4 - (n+3)^4$$ | $$\binom{4}{1}(4^1-3^1) n^3 + \binom{4}{2}(4^2-3^2) n^2 + \binom{4}{3}(4^3-3^3) n + \binom{4}{4}(4^4-3^4)$$ |

## 3. 2階差分 ($\Delta^2$)

|  $k$  | 左辺                                                            | 右辺                                                                                                                                                 |
| :---: | :-------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0** | $$\left((n+2)^4-(n+1)^4\right) - \left((n+1)^4-(n+0)^4\right)$$ | $$\binom{4}{2}\left[(2^2-1^2)-(1^2-0^2)\right] n^2 + \binom{4}{3}\left[(2^3-1^3)-(1^3-0^3)\right] n + \binom{4}{4}\left[(2^4-1^4)-(1^4-0^4)\right]$$ |
| **1** | $$\left((n+3)^4-(n+2)^4\right) - \left((n+2)^4-(n+1)^4\right)$$ | $$\binom{4}{2}\left[(3^2-2^2)-(2^2-1^2)\right] n^2 + \binom{4}{3}\left[(3^3-2^3)-(2^3-1^3)\right] n + \binom{4}{4}\left[(3^4-2^4)-(2^4-1^4)\right]$$ |
| **2** | $$\left((n+4)^4-(n+3)^4\right) - \left((n+3)^4-(n+2)^4\right)$$ | $$\binom{4}{2}\left[(4^2-3^2)-(3^2-2^2)\right] n^2 + \binom{4}{3}\left[(4^3-3^3)-(3^3-2^3)\right] n + \binom{4}{4}\left[(4^4-3^4)-(3^4-2^4)\right]$$ |

## 4. 3階差分 ($\Delta^3$)

|  $k$  | 左辺                                                      | 右辺                                                                                                                                                                                                  |
| :---: | :-------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0** | $$\left(\Delta_{2,1}\right) - \left(\Delta_{2,0}\right)$$ | $$\binom{4}{3}\left[ \left((3^3-2^3)-(2^3-1^3)\right) - \left((2^3-1^3)-(1^3-0^3)\right) \right] n + \binom{4}{4}\left[ \left((3^4-2^4)-(2^4-1^4)\right) - \left((2^4-1^4)-(1^4-0^4)\right) \right]$$ |
| **1** | $$\left(\Delta_{2,2}\right) - \left(\Delta_{2,1}\right)$$ | $$\binom{4}{3}\left[ \left((4^3-3^3)-(3^3-2^3)\right) - \left((3^3-2^3)-(2^3-1^3)\right) \right] n + \binom{4}{4}\left[ \left((4^4-3^4)-(3^4-2^4)\right) - \left((3^4-2^4)-(2^4-1^4)\right) \right]$$ |

## 5. 4階差分 ($\Delta^4$)

|  $k$  | 左辺                                                      | 右辺                                                                                                                                                                                                |
| :---: | :-------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **0** | $$\left(\Delta_{3,1}\right) - \left(\Delta_{3,0}\right)$$ | $$\binom{4}{4} \left[ \left( \left((4^4-3^4)-(3^4-2^4)\right)-\left((3^4-2^4)-(2^4-1^4)\right) \right) - \left( \left((3^4-2^4)-(2^4-1^4)\right)-\left((2^4-1^4)-(1^4-0^4)\right) \right) \right]$$ |

---

### 最終結果（交代和）

$f(k) = k^4$ の4階差分 $\Delta^4 f(0)$ を、項 $0^4, 1^4, 2^4, 3^4, 4^4$ を使って計算します。

$$\Delta_{4,0} = \sum_{j=0}^{4} \binom{4}{j} (-1)^{4-j} j^{4} = 4!$$

|         差分         | 展開された交代和の式 $=$ 最終定数                                                                                                        |
| :------------------: | :--------------------------------------------------------------------------------------------------------------------------------------- |
| **$\Delta^4 (0^4)$** | $$\binom{4}{0} (-1)^4 0^4 + \binom{4}{1} (-1)^3 1^4 + \binom{4}{2} (-1)^2 2^4 + \binom{4}{3} (-1)^1 3^4 + \binom{4}{4} (-1)^0 4^4 = 24$$ |
